# Терминал защиты депозита (Анти-Тильт)

Простое мобильное веб-приложение (PWA): калькулятор сделок «Фикса», «Мартингейл (Умное перекрытие)», «Анти-Мартингейл (Разгон)» и панель «Анти-Тильт» с автоматическим СТОП-ТОРГИ.

- Чистый HTML/CSS/JS, без сборки. Открывается в любом браузере (Android, iPhone/iPad, ПК); можно добавить на главный экран.
- Тесты математики: `node test/math.test.js`.

Это только калькулятор, не финансовая рекомендация. Торговля связана с риском потери депозита.
